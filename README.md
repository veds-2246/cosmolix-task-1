# new
1.What is git?
Git is a free, open-source distributed version control system designed to track changes in computer files and coordinate work among multiple people. 

2.What is github?
GitHub is a cloud-based platform where developers store, share, and collaborate on software code. 

3.Why developers use Git?
Developers use Git primarily to manage and track changes in their source code over time, a process known as version control. It acts like a "save point" system for software, ensuring that no work is lost and that multiple people can build the same project simultaneously without overwriting each other.
